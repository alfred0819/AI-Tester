# Phase 2 — 2002 核心战斗系统

## 目标

气槽可见可用；指令必杀与超必杀可放；普攻可取消进必杀；具备紧急回避（或等价闪避）。

## 任务清单

- [ ] `InputBuffer` + 指令匹配（`236P`、`623P` 至少各一）
- [ ] `PowerGauge`：涨气/耗气；HUD 格数
- [ ] 每角色 2 必杀 + 1 超必杀（耗 1 格或满槽，表驱动）
- [ ] `CancelRules`：指定 cancel 窗口 tag
- [ ] 紧急回避：耗气或无气版本二选一（建议轻耗气）
- [ ] 弹道类 HitBox（青影/赤焰用）与生存期
- [ ] （可选）简易 Guard Crush 条

## 验收

1. 训练场固定顺序能打出「轻拳 → 取消必杀 → 超必杀」
2. 无气时超必杀不能放；有气时正确扣减
3. 回避期间有无敌帧且可躲开一次打击
