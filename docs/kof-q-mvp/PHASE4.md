# Phase 4 — Training、Arcade、简易 AI

## 目标

三种模式可从标题进入；训练场便于调帧；Arcade 用 CPU 打完短线路。

## 任务清单

- [ ] **Training**：锁血、锁气、一键复位、对手站立/蹲防/跳、显示帧数与当前招式 id
- [ ] **Arcade**：1P 选 3 人，打 3～4 关固定敌队
- [ ] `AiController`：距离门限决定靠近/后撤；随机防御；CD 到放必杀；对空升龙类（有则用）
- [ ] 难度一档即可（可后加 Easy/Normal）
- [ ] 暂停菜单：回标题 / 重开

## 验收

1. Training 可稳定练习 Phase 2 连招并复位
2. Arcade 通关或失败都有结算并回标题
3. CPU 不会发呆站桩超过数秒（会移动或攻击）
