# Q 版格斗 MVP 验收清单

勾选即视为对应项通过。

## 工程与模式

- [ ] Godot 4 打开 `KofQMvp/` 可直接运行
- [ ] Title 可进 Versus / Training / Arcade
- [ ] Versus：双方选 3 人顺序后进入对战
- [ ] Training：锁血锁气、复位、假人防/站
- [ ] Arcade：至少 3 关 CPU，有胜负回退

## 战斗系统

- [ ] 走、跑或冲、跳、蹲可用
- [ ] 轻/中（或轻中重）普攻可命中与防守
- [ ] Hitstop、击退、硬直可感知
- [ ] 指令必杀至少每角色 2 个可稳定输入打出
- [ ] 气槽涨耗正确；超必杀耗气
- [ ] 普攻取消进必杀在训练场可复现
- [ ] 紧急回避可躲一次攻击（含无敌帧）
- [ ] KO 换人；三人全倒判负
- [ ] 队伍气槽规则与文档一致（共享气槽）

## 内容与表现

- [ ] 4 个原创角色均可选用（名称/视觉非 SNK 资产）
- [ ] Q 版剪影攻击可读；血条/气槽/队序 HUD 完整
- [ ] 无商业 ROM 拆包资源

## 手感底线

- [ ] 逻辑 60 FPS；本地 2P 同屏无严重掉帧（目标机）
- [ ] 输入缓冲下，标注的入门连招成功率高（人为练习 10 次≥7 次）
