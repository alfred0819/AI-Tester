# Phase 3 — 小队 3v3 + 角色数据化

## 目标

选人界面为双方各选 **3 人不重复顺序**；击倒后换下一人跳入；**4 个 CharacterDef** 均有可玩招式表（深度可不均，但都能进队）。

## 任务清单

- [ ] `TeamOrder`：3 槽位、当前 index、剩余人数
- [ ] 选人 UI：点选顺序、P1/P2 确认
- [ ] KO → 退场 → 下一人入场（入场无敌 30～45 帧）
- [ ] 三人全倒 → 胜负
- [ ] 将 C01～C04 拆成 data Resource；Fight 只读 id 生成
- [ ] HUD 显示队序头像与剩余

## 验收

1. 完整一局 3v3 本地对战可从选人打到胜负
2. 换人后气槽规则明确（建议：**继承队伍气槽** 或 **个人气槽重置**，选定一种写进 balance 表并全程一致）
3. 4 角色均可被选入队伍

## 气槽继承（本规划默认）

**整队共享一条气槽**（更接近小队资源博弈，实现简单）。换人不清零。
