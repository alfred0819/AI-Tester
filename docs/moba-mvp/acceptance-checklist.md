# MVP 验收清单

用途：每个 Phase 结束对照勾选；全部勾选即「能玩」达标。

## 联网与房间

- [ ] 同一局域网可创建房间并加入
- [ ] 1v1：2 名玩家进入同一战场
- [ ] 3v3：最多 6 名玩家；缺人可用 Bot 补位
- [ ] 选人确认后同步加载场景

## 操作与战斗

- [ ] 摇杆八向移动，速度符合配置
- [ ] 普攻可锁定英雄/小兵/塔
- [ ] 4 名英雄均能释放完整技能组（含大招）
- [ ] 眩晕/减速等状态可生效且有时长
- [ ] 死亡后倒计时复活并在泉水满状态出生

## 兵线与建筑

- [ ] 定时出兵，兵线会交战
- [ ] 塔会攻击范围内敌人
- [ ] 摧毁高地塔后可攻击水晶（若实现门禁）
- [ ] 摧毁水晶立即结束对局并显示结算

## 经济

- [ ] 补刀/击杀获得金币
- [ ] 商店可购买至少 6 件装备且属性生效
- [ ] Host 拒绝金币不足的购买

## 体验底线

- [ ] 两台真机同 Wi‑Fi 完成一局 1v1 推水晶
- [ ] 中端机目标约 60 FPS（允许偶发掉帧）
- [ ] 无正版商用素材混入（角色/UI/音频均原创或占位）

## Phase 出口（建议）

| Phase | 最少可演示内容 |
|-------|----------------|
| 0 | 两人连上，场景里看到对方胶囊体 |
| 1 | 互殴掉血、死亡复活 |
| 2 | 兵线推塔推水晶，出结算 |
| 3 | 4 英雄可选，商店可用 |
| 4 | 3v3 含 Bot 开局 |
| 5 | 真机验收清单全部勾选 |
