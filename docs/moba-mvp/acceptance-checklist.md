# MVP 验收清单

用途：Phase 5 结束后对照勾选；全部勾选即「能玩」达标。

## 联网与房间

- [ ] 同一局域网可创建房间并加入（Port 作为房间码）
- [ ] 1v1：2 名玩家进入同一战场
- [ ] 3v3：最多 6 名；缺人可用 Bot 补位
- [ ] 选人后同步加载场景

## 操作与战斗

- [ ] WASD 移动；按住 Q/R/E 可见技能指示器
- [ ] 普攻范围内出现锁定红环
- [ ] 4 名英雄技能组可用；受击有飘字/闪白
- [ ] 眩晕/减速生效
- [ ] 死亡复活回泉水

## 兵线与建筑

- [ ] 定时出兵并交战
- [ ] 塔会攻击敌人
- [ ] 拆塔后可打水晶
- [ ] 拆水晶出结算（含 KDA/金币/时长）并可回大厅

## 经济

- [ ] 补刀/击杀/推塔得金币
- [ ] 商店 6 件装备可买且属性生效
- [ ] 金币不足无法购买

## Phase 6 体验

- [ ] 左下角小地图可见英雄/塔/水晶点
- [ ] `T` 回城读条；移动或受伤可取消
- [ ] 1v1 对手断线给出胜负；3v3 掉线补 Bot

## 体验底线

- [ ] 两台真机同 Wi‑Fi 完成 1v1 推水晶
- [ ] 中端机约 60 FPS（允许偶发掉帧）
- [ ] 无正版商用素材（均为原创/占位）
- [ ] 对局时长大致落在可破高地的节奏（约 8–15 分钟量级，视对抗强度）

## Phase 出口

| Phase | 内容 |
|-------|------|
| 0–4 | 骨架→战斗→推塔→英雄装备→3v3 Bot |
| 5 | 手感反馈 + 验收清单可勾选 |
| **6** | **结算战绩 + 小地图 + 回城 + 断线策略** |
