# Phase 6 — 结算 / 小地图 / 回城 / 断线

MVP 之后的可玩性补全：战绩结算、战场态势、回城读条、掉线策略。

## 功能

| 功能 | 说明 |
|------|------|
| 结算战绩 | 摧毁水晶后展示胜负、时长、各英雄 KDA 与金币 |
| 助攻 | 击杀前 10s 内造成伤害的友方获助攻 + 金币 |
| 小地图 | HUD 左下角俯视点：英雄 / 塔 / 水晶 |
| 回城 | `T` 读条约 4.5s；移动 / 受伤 / 眩晕取消；完成后回泉水 |
| 断线 | **1v1**：对手掉线 → 剩余方胜；**3v3**：补一只 Bot |

## 操作补充

- `B` 商店（不变）
- `T` 回城
- HUD 显示 `KDA` 与回城倒计时

## 本机

**MobaMVP → Setup Phase 0–6 Scenes And Prefabs** 后 Play。
