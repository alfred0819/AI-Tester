# Phase 3 — 四英雄 + 装备商店 + 状态效果

## 目标

数据驱动四英雄技能、六件装备商店、眩晕/减速/护盾/加速。

## 英雄

| 英雄 | 定位 | 技能概要 |
|------|------|----------|
| 磐卫 | 坦克 | 盾击眩晕 / 铁壁护盾 / 冲阵位移+眩晕 |
| 影袭 | 刺客 | 影步位移 / 裂痕锥形减速 / 绝杀爆发 |
| 烬法 | 法师 | 炎弹锥形 / 霜域落点减速 / 烬狱大范围 |
| 穿云 | 射手 | 穿甲矢 / 疾风加速 / 万箭落点 |

大厅下拉选择英雄；进场后由客户端 RPC 同步给 Host。

## 装备（B 打开商店，开局 500 金）

精铁刃、奥术杖、疾行靴、锁子甲、活力坠、时砂符（CD 缩减）

## 操作

| 按键 | 动作 |
|------|------|
| WASD | 移动 |
| J / LMB | 普攻 |
| Q / 1 | 技能 1 |
| R / 2 | 技能 2 |
| E / 3 | 技能 3 |
| B | 商店 |

## 本机

1. Unity 打开 `MobaMVP/`
2. **MobaMVP → Setup Phase 0–3 Scenes And Prefabs**
3. Lobby 选英雄 → Host → Start Match
4. 买装备、放技能、推塔

## 单测

`dotnet test MobaMVP/src/Moba.Core.Tests` — 含英雄/装备/状态用例。
